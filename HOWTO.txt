КАК ЗАЛИТЬ В GITHUB
===================

Вариант 1 (рекомендуется): через сайт GitHub
--------------------------------------------
1. Открой свой репозиторий.
2. Add file -> Upload files.
3. Перетащи ПАПКУ FakePass13 целиком (из этого архива) в окно браузера.
4. Нажми Commit changes.
5. Actions -> последний запуск -> артефакт FakePass13 -> внутри .deb

Получится так:

  репозиторий/
    FakePass13/
      Makefile
      Tweak.xm
      control
      prefs/
      layout/
      .github/

Это правильная структура, workflow её понимает.

Вариант 2: через git
--------------------
1. Распакуй архив.
2. Скопируй содержимое папки FakePass13 в свою локальную копию репозитория
   (так, чтобы Makefile оказался в корне репозитория).
3. Затем:

   git add -A
   git commit -m "FakePass13 1.2.0"
   git push

ВАЖНО
-----
* Корневой Makefile должен содержать строку: TWEAK_NAME = FakePass13
  (если там BUNDLE_NAME - это файл из prefs/, его нельзя класть в корень).
* Файл prefs/FakePass13RootListController.m должен лежать именно в папке prefs.
* Не заливай .theos/, packages/ и *.deb.

ЧТО ПРОВЕРИТЬ НА ТЕЛЕФОНЕ
------------------------
1. После установки .deb сделай respring.
2. Настройки -> FakePass13 (внизу списка).
3. Нажми "Заблокировать сейчас" - должен появиться экран с часами и клавиатурой.
4. Код по умолчанию: 1234.
5. "Показывать после respring" включай только после успешной проверки.

Если пункт в Настройках есть, а замок не появляется - пришли содержимое
/tmp/fakepass13.log (или /var/mobile/Library/Caches/fakepass13.log).
